Editing a copy in memory
REDUX SAVE STUDIO / v1.5.0

From edit to in-game.

  1. Save in-game, then fully close your emulator. Use the battery save from your emulator’s save folder, not a savestate.
  2. Open the .sav or .srm here. Download an original backup. Changes apply only when you click an Apply button.
  3. Edit, then review and export. You can undo changes. Export preserves the input’s size and all unrelated data.
  4. Replace your emulator’s battery save. Match the ROM’s save filename and extension. Start the game normally through its Continue menu. Loading an old savestate can restore the old data.

Abilities and innates come from the ROM’s species data or its randomizer. To change a randomized combination, use Ability lab with the corresponding randomizers enabled.

Species, move and ability data is bundled for Elite Redux 2.65.4 (also used by 2.65.4.1b) and 2.65.4.11b, from ER Nextdex. A save does not identify its ROM build, so choose your version next to the file name: every randomized ability and innate depends on it, because each build has a different number of abilities. Other builds can import their own Nextdex JSON in Game settings.

Privacy

Last updated October 2026.

Your save file

The editor reads and edits your save entirely inside your browser. The file is never uploaded, sent to a server or stored anywhere after you close the page. Downloads (backups and edited saves) are created on your own device.

What the editor collects

Nothing. There are no accounts, cookies, analytics, ads or tracking scripts, and the page makes no network requests after it loads. Pokémon artwork and game data are built into the page.

Hosting

The online version is served by GitHub Pages. GitHub may log basic request information such as your IP address when the page is loaded; see GitHub's privacy statement. The downloaded offline editor makes no requests at all.
